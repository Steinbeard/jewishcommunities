# kehillah_learn_torah_decisions.txt's own header for the full design
# account (both decisions, the flat-not-chained shape, the community
# library this reads). See events/kehillah_learn_torah_journey_events.
# txt for the travel-to-study-elsewhere counterpart to kehillah_learn_
# torah.0001 below, ADDED the same day.
#
# TWO NAMESPACES IN ONE FILE, deliberately -- kehillah_learn_torah and
# kehillah_acquire_torah_work are two different decisions' own event IDs,
# not two steps of one chain, so they get two separate `namespace =`
# declarations rather than sharing one the way this mod's other multi-
# event files (one decision, several chained events) do.
#
# THE RANDOM_LIST "WHICH WORK" PATTERN, both events: each track's four
# works appear as flat, equal-weight random_list entries, each entry's
# OWN trigger checking whether the relevant library owns (or, for
# Acquire, does NOT own) that specific work -- an entry whose trigger
# fails is simply skipped, the identical idiom kehillah_bet_din_draw_
# case_effect already uses to pick among not-yet-heard cases (common/
# scripted_effects/kehillah_bet_din_scripted_effects.txt) and kehillah_
# translation_pick_work_effect already uses for the Translation
# Contract's own ten-work pool. Each option's own OUTER trigger (the
# kehillah_owns_/missing_<track>_work_trigger checks, common/scripted_
# triggers/kehillah_scripted_triggers.txt) already guarantees at least
# one entry is eligible before the option is ever shown, so there is no
# empty-random_list case to guard here the way the Bet Din's own draw
# does (that one can legitimately draw nothing in a session; this
# cannot, by construction of its own gating).
#
# kehillah_learn_torah.0001's THREE OPTIONS ARE NOW THIN, ADDED
# 2026-09-15 -- each just gates on ownership and calls the matching
# kehillah_study_<track>_effect (common/scripted_effects/kehillah_
# library_effects.txt) with LIBRARY = primary_title. That effect owns
# the random_list/pass-fail/already-studied logic now, shared verbatim
# with kehillah_learn_torah_journey.0001's own three options (LIBRARY =
# var:kehillah_journey_destination_title instead) -- see that shared
# effect's own header for the full "why one effect, not two copies"
# account, including the already-studied tracking this pass added.
# =====================================================================

# kehillah_learn_torah.0001 (STUDY AT THE BEIT MIDRASH) is RETIRED as of

# directly; see that decision's own header (common/decisions/kehillah_
# learn_torah_decisions.txt) for the full account of what replaced it
# (the kehillah_study_torah scheme, common/schemes/scheme_types/kehillah_
# study_torah_scheme.txt, and its own events/kehillah_study_torah_
# events.txt). kehillah_study_parshanut_effect/_talmudics_effect/_
# hashkafa_effect (common/scripted_effects/kehillah_library_effects.txt)
# are DEAD as of the same pass -- nothing else ever called them, per a
# repo-wide grep at retirement time -- and are not carried forward; the
# scheme's own resolve path goes through kehillah_study_specific_work_
# effect instead (already shared with the travel journey since
# 2026-09-17).
