# =====================================================================
# Kehillah Sh'um events -- the Bet Din's takkanot (communal ordinances).
#
# Source of truth: docs/spec/v4-regional-communities-and-batei-din.md
# section 4. Fired by kehillah_shum_takkanah_decision (common/decisions/
# kehillah_decisions.txt), which gates who may convene the Bet Din
# (a Sh'um member's leader, and only the current Greatness leader among
# the three) and carries the long (15-year) cooldown. This event is the
# ruling itself: three named, historically-grounded takkanot to choose
# from, each applied to ALL THREE Sh'um member titles at once via their
# primary_title-equivalent (title:c_kehillah_worms/speyer/mainz) scopes
# directly -- there is no single "convener's community" that benefits
# alone; a Bet Din ruling binds the whole confederation, per spec
# section 4's "effects apply symmetrically... across all three member
# titles" design.
#
# THE THREE TAKKANOT, EVERY TIME -- real ordinances of the historical
# Takkanot Shu"m (see Wikipedia "Takkanot Shu"m" and the Jewish
# Encyclopedia's "SYNODS" article, both consulted 2026-09-08), each
# picked because it survives in the actual historical record, not
# invented for flavor:
#   BAN ON INFORMING (issur mesirah) -- the best-documented and most
#     consequential of the historical takkanot: a communal cherem on
#     informing to gentile authorities against a fellow Jew. Reads as
#     protection/trust, so the biggest Stability number of the three.
#   ORDINANCE ON WEDDING EXTRAVAGANCE -- the historical Shu"m communities
#     did legislate sumptuary limits on wedding celebrations, precisely
#     to stop competitive overspending from breeding communal jealousy
#     and hardship. Stability (less friction) plus a Prosperity
#     component (less ruinous overspending) -- the one takkanah that
#     isn't pure Stability, reflecting its more economic character.
#   ORDINANCE PROTECTING WIDOWS -- communal protections for widows
#     (inheritance, remarriage/agunah safeguards) are also part of the
#     historical takkanot record. Stability plus Greatness -- compassion
#     for the vulnerable read as communal virtue as much as cohesion,
#     mirroring how kehillah_leadership.txt already scores communal
#     office on Judaism's own listed virtues.
#
# No skill check, unlike the dispute events -- this is a collective,
# deliberated ruling by the Bet Din as a body, not one leader's
# individual judgement call the way a family dispute is. All three
# options are always available; the choice is which ordinance the
# convened Bet Din takes up, not whether the leader is competent enough
# to rule well.
# =====================================================================
