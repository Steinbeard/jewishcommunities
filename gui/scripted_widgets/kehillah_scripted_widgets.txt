# =====================================================================
# Kehillah scripted-widget registrations.
#
# This is CK3's one additive GUI mechanism -- the only way found, across
# two research passes in this repo (docs/spec/gui-spike-community-list.md,
# docs/spec/spike-domicile-map-visibility.md), to put a new element on
# screen without forking a vanilla .gui file. The engine's own
# documentation for it is game/gui/scripted_widgets/_scripted_widgets.info:
#
#   "Files here can contain pairs of file path and widget names to
#    automatically create widgets on startup that are not formally
#    referenced by the code."
#   "All files will be loaded so multiple mods can load their own widgets
#    as long as they don't mess with each other's pathing."
#
# -- i.e. this file MERGES with other mods' registrations rather than
# overwriting them, which is exactly the property the two spikes went
# looking for and could not find anywhere else. Vanilla ships the folder
# with only the .info file in it, so nothing is being overridden here.
#
# Entries: the Jewish Communities map view's roster and policy legend,
# and the realm view window. (The map-mode buttons and "Showing:" names
# moved into the mod's gui/shared/mapmodes.gui copy on 2026-10-29.)
# =====================================================================

# The Jewish Communities map's roster ("ledger") window and its minimized
# header were retired 2026-11-08 at Daniel's request; the map's hover card
# carries the community's facts instead. Their definitions stay in
# gui/kehillah_community_map_view.gui, unregistered, so nothing creates them.
# See docs/implementation/2026-11-08-jewish-map-category.md.

# The domicile tab and attached library live in our 1.20.1
# gui/window_domicile.gui override, so they move with that window; nothing
# from gui/kehillah_domicile_library.gui is registered here any more.

gui/kehillah_realm_view.gui = kehillah_realm_view_window

# The policy map's colour legend (2026-10-28).
