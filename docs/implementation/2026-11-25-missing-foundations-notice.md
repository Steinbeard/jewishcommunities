# Missing Foundational Works notice

Daniel asked for a top-bar notice when a Kehillah leader's library is missing foundational works
and no sefer is being acquired.

**When it shows** (`action_kehillah_library_missing_foundations`,
`common/important_actions/kehillah_library_foundation_actions.txt`): a human Kehillah leader, adult
and free, whose primary title has `kehillah_lib_foundational_missing_count_value > 0` and no
`kehillah_library_commission_work` list. That count is the same one that already costs
Greatness (`kehillah_bd_foundational_works_value`): works that circulate by now and stand at
Foundational or higher in the leader's rite. The description gives the count.

**What a click does.** It opens the library window on the community's own shelf, where the
foundational centrepiece and its alert name the missing works and each can be sought. An
important action's effect cannot set GUI variables, and the library window opens only through
them. So the effect sets a one-day `var:kehillah_lib_open_request` on the player. A new
zero-size scripted widget, `gui/kehillah_library_opener.gui`, shows while that variable exists.
Its `_show` runs scripted GUI `kehillah_lib_open_request_consume`, which clears the request and
points `kehillah_lib_view_owner` and `kehillah_lib_view_title` at the player's library. It then
clears the window's selections, lays out the shelf, and opens the window, the same steps as the
Libraries map click. Clearing the variable hides the widget again, so the next click fires again.
Other script can reuse this to open the library.

**Live checks still needed** (the new widget needs a game restart to load):
- the notice appears for a leader missing a foundational work, with the right count;
- one click opens the library on the community's shelf, and a second click after closing it
  opens it again;
- the notice clears once a commission starts and stays away until it ends;
- `error.log` shows no new lines from the opener.

**Addendum 2026-11-25 — the notice names the works.** Daniel's first look: the notice said one work
was missing, but the shelf showed none. The shelf's foundation alert covers only the Shas and
Karaite cases; a missing Parshanut or Machshavah work had no name anywhere. The notice now lists the
first five missing works by name and adds "and others" past five. As it checks, it runs
`kehillah_lib_note_missing_foundations_effect`. That effect keeps them in
`var:kehillah_lib_missing_found_1..5` on the leader, using the same rules as the count. The effect
and its custom loc (`KehillahLibMissingFoundLine<n>`, `KehillahLibMissingFound<n>Name`) are
generated by `write_missing_foundation_files` in `scripts/kehillah_library_catalog.py`. It was run
alone this time, so the other generated files were left as they were. Live check: the names
match the count and clear as works arrive.

**Addendum 2026-11-25 — a decision to pick the work; dynamic label.** Daniel asked for a decision
the notice opens, listing the missing works to choose from, with the choice going through the
existing acquisition flow. This replaces the click target above. The library opener widget stays,
unused, for any future script that needs to open the library.

- **Acquire a Foundational Work** (`kehillah_acquire_foundational_work_decision`,
  `common/decisions/kehillah_library_foundation_decisions.txt`, generated). Shown to a human
  Kehillah leader whose library has missing foundational works. Valid while adult, free and with
  no copy already being sought. Vanilla's `decision_option_list_controller` lists one item per
  catalog work, each shown only while that work is a missing foundational one (the count's
  rules). Confirming runs `kehillah_lib_acquire_picked_foundation_effect`. That effect rebuilds
  the acquisition candidates, sets the commission work and fires `kehillah_library.0002`, the
  same source-and-price confirmation as the Library's Seek button. Players only: the AI keeps
  `kehillah_acquire_torah_work_decision`.
- **The notice** now opens that decision. Its label is the work's name when one is missing
  ("Missing: Targum Onkelos"), else the count ("3 Missing Foundational Works"), through custom
  loc `KehillahLibMissingFoundLabel`.
- All of it is generated by `write_missing_foundation_files` (run alone again).

Live checks: the label with one and with several missing works; the click opens the decision;
the list shows exactly the named works; confirming reaches the 0002 confirmation for the chosen
work; the decision is greyed out while a copy is on its way.
