# CK3 1.21 cleanup

## 1. Vanilla overrides against 1.21

`xtiger_overrides` was run against the installed 1.21.0.3, with the 1.20 game at `D:\ck3-base-1.20` as the base. That
base separates the mod's own edits from changes the game made since. Of 116 overridden definitions:

- **Current:** every definition override already carries 1.21's text. The 1.21 port, merged 2026-11-22, did this. The
  remaining differences are the mod's deliberate edits:
  - Jewish names, icons and tenets;
  - no `special_doctrine_prophecy_of_malachi` (the 2026-11-14 faith revision);
  - the Kehillah gates on council positions and tasks.

  This includes the tenets 1.21 gave trade bonuses (esotericism, legal pronouncements, ritual celebrations), the
  pilgrimage activity and the Bavlim and Sephardi traditions.
- **Stale: `events/dlc/ep3/ep3_laamp_decision_events.txt`**, a whole-file copy of 1.20's Roads to Power decision events,
  carrying the visit bridge's three hunks:
  - `id_override_priority` on `.1000`;
  - the Tavern row's label;
  - the Tavern row's destination.

  Because it was a 1.20 copy, it replaced 1.21's file in game:
  - it read `development_level` and `county_opinion`;
  - it lost 1.21's balance changes;
  - it brought back nine events 1.21 removed, which referenced removed effects.

  It was **rebuilt on 1.21's file with the same three hunks** (35 xTiger reports fixed). The file is **untracked**: it
  belongs to another session's uncommitted visit-bridge work, so it is left uncommitted. The 1.20 copy is backed up in
  that session's scratchpad.
- **Tidied:** the three minhag rites (Ashkenaz, Sepharad, Yerushalmi) now list 1.21's `doctrine_diet_unrestricted` and
  `doctrine_alcohol_permitted`, as Rabbinism does. Vanilla leaves these off some rites, so this was not an error.

## 3. The Affluence rename

1.21 has its own county **Prosperity** (`county_prosperity`). The community pillar's **display name** is now
**Affluence**:

- **What changed:** 95 loc values in 23 files. Only text outside `[...]` data functions and `$...$` references changed
  (`scratchpad/affluence.py`).
- **What did not:**
  - keys, script and variables (`kehillah_var_prosperity`, `KehillahProsperityScore` and so on);
  - the GUI, whose matches are code and vanilla's own `County.GetProsperity*`;
  - the docs, which still call the pillar Prosperity internally;
  - lowercase "county prosperity", which means 1.21's;
  - general prose such as "guide your people to prosperity".
- **Two loc files held other sessions' edits:** `kehillah_l_english.yml` and `kehillah_community_news_l_english.yml`.
  For those, the rename was staged onto their committed versions and also applied in the working copy.

**Noticed, not changed:** the Commercial leadership style still describes a "+60 Affluence baseline". Pillars R2 retired
the flat +60 on 2026-11-20, so that text is stale on its own account.
