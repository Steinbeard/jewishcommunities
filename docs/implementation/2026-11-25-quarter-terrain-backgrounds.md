# Quarter terrain backgrounds
**Status: WIRED 2026-11-25; live rendering and selection pending.**

Daniel requested the five terrain studies for the MENA architecture set and asked to make both regions playable. Built-in imagegen edited `kehillah_quarter_background_mena_lived_v4.png` into mountain, desert, wetlands, jungle and coastal scenes; it was instructed to preserve the houses, road, courtyard, residents, framing and watercolor style, changing distant landscape and edge vegetation. The five Western studies are documented in [the earlier note](2026-11-25-western-terrain-background-studies.md). All ten retained `_study.png` source paintings have been visually inspected as artwork, not as game-aligned composites.

`scripts/kehillah_quarter_terrain_backgrounds.py` packs the ten source images into 2412×1112 DXT1 DDS. `scripts/kehillah_quarter_wire_terrain_backgrounds.py` inserts the asset blocks. Mountain, desert/desert mountains, wetlands and jungle take precedence over coastal county; coast uses vanilla's `domicile_location.county = { is_coastal_county = yes }`. Hills, drylands, oasis and steppe retain existing terrain fallback if inland. Western normal/harsh winter takes precedence over every terrain and uses the existing snowy Western Quarter; no terrain-specific winter images are supplied. MENA keeps its terrain scene in winter. East Asian selection remains vanilla. Existing pins and slot geometry are untouched. Foregrounds use vanilla rough, dry, green, jungle or urban textures as appropriate.

Static verification: all ten DDS exist, decode at the expected dimensions, and have one corresponding asset reference each. The images are not reliable in-game placement previews. After restarting CK3, a Luna tester should check each region and terrain, the vanilla foreground, site overlap, a coastal county, a coastal county with a higher-priority terrain, Western winter/thaw, and the Asian fallback; compare error logs with the boot baseline. No Luna tester was available for this pass.

The shared checkout xTiger baseline and post-change report are identical except source line numbers: 0 fatal, 447 errors, 808 warnings, 37 untidy and 152 tips.
