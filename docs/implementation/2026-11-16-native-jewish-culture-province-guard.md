# Native Jewish culture seeding: counties without provinces

**Status:** source, xTiger and 1066/867 isolated live boot checks passed 2026-11-16; further map and 1178 checks optional. This is a runtime correction to the implementation in [the Jewish cultures map record](2026-11-08-jewish-cultures-map.md), not a change to its culture geography. See the [isolated live log](../testing/2026-11-16-native-jewish-culture-guard-live-log.md).

The pre-alpha screenshot pass revealed a large `error.log` flood on entering a 1066 campaign. The engine reported `title_province trigger [ Failed context switch ]` **7,074 times** through `kehillah_seed_native_jewish_cultures_effect` at game start. The nine region checks in `kehillah_jewish_culture_homeland_effects.txt` each failed **786 times**. The exact affected title IDs were not logged, but the repeated pattern points to county iterations without a usable `title_province` link. This was not caused by opening the Jewish map or Domain UI: the count stayed unchanged after those panels were opened. CK3's own installed scripts use `exists = title_province` before following that link in comparable cases.

The seed loop now visits only counties with a province link. This leaves their normal broad-geography and minhag rules unchanged, while county titles without map geography receive no native-culture seed. The later North Europe clearing loop uses the same guard. The rest of the named-duchy overrides and 867 emergence logic are unchanged.

Before and after xTiger totals match at **0 fatal, 32 errors, 126 warnings, 37 untidy, 135 tips**. The tool finds no new diagnostic in the touched file. In a fresh isolated 1066 Granada boot mounted from this worktree, the `title_province trigger [ Failed context switch ]` count was **zero**, down from 7,074. The log still flooded from the *separate* unguarded leadership-style variable on `origin/master`; its fix lives in [the pre-alpha guide PR](https://github.com/Steinbeard/jewishcommunities/pull/71). With both guards in the shared checkout, a second 1066 live boot again showed zero of both targeted signatures; the log fell to **1,937 lines**, including other bounded script errors, and stayed there through Jewish Cultures map interactions. Iberia painted magenta and two county hovers identified Sephardi as intended. An 867 Amram Gaon boot also showed zero context-switch errors and no lines from the culture-seeding file, covering the pre-Ashkenaz forerunner path at game start. The map view and 1178 date were not exhaustively checked.
