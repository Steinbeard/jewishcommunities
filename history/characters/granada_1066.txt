# ibn Naghrilla ("Samuel HaNagid"), succeeded his father as vizier of the
# Zirid Taifa of Granada on Samuel's death in 1056 and held that position
# continuously through this scenario's own 1066.9.15 start date --
# genuinely the most powerful Jewish courtier anywhere in the Islamic
# world at this exact moment, commanding real political and (through his
# father's own legacy) military authority, not merely communal standing.
#
# STATED PLAINLY, THE SAME HONESTY THIS MOD ALREADY APPLIES TO YORK'S
# 1190 AND LINCOLN'S 1255 (see the old, now-removed Anglia start effects'
# own headers, and kehillah_setup_granada_start_effect's neighbouring
# note, common/scripted_effects/kehillah_scripted_effects.txt): the real
# Granada massacre of 30 December 1066 -- barely three and a half months
# after this scenario's start -- killed Joseph ibn Naghrilla and, per the
# traditional account, most of the city's Jewish population, one of the
# most catastrophic single episodes in medieval Sephardi history. This
# pass deliberately does NOT script that outcome: no forced death, no
# pogrom event, no timer. He is seeded exactly as he really stood on this
# scenario's own start date, free to live or die by ordinary play (or a
# future dedicated crisis chain, flagged as a strong candidate in
# ROADMAP.md's backlog and not built here).
#
# Dynasty: dynn_Naghrilla (9000054, common/dynasties/ha_levi.txt -- newly
# added this pass; no existing reserved sephardi dynasty name in that
# file belongs to this specific, distinctly documented family). Faith:
# rabbinism. Culture: sephardi. Granada itself confirmed an independent
# Zirid Taifa (Emir Badis ibn Habus, holder since 1038) at this exact
# date.
#

# not a rabbinic scholar (that was never his own real public role, unlike
