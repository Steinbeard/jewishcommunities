# Kalonymus (representative figure) — the nascent Speyer community.
#
# Source of truth: v4 spec section 5, implementation-time research done
# 2026-09-08 (see docs/spec/v4-regional-communities-and-batei-din.md).
#
# THE ANACHRONISM, STATED PLAINLY. Speyer's Jewish community is NOT
# documented as existing in 1066. Checked directly (English Wikipedia,
# "History of the Jews in Speyer", 2026-09-08): "the first records of
# Jews in Speyer appear in the 1070s. They were members of the renowned
# Kalonymos family of Mainz, which had migrated a century before from
# Italy." The organized community proper begins later still, in 1084,
# when Bishop Rudiger Huzmann's charter formally invited Jewish
# settlement (partly refugees from Mainz/Worms pogroms). Both dates are
# after this mod's 1066 scenario start.
#
# WHY SPEYER IS SEEDED ANYWAY. v4 spec section 5 calls for Speyer as one
# of the three Sh'um member communities from game start, alongside Worms
# and Mainz, so the Bet Din mechanic has all three members playable/
# AI-run from turn one rather than requiring a Wave-5-style mid-game
# founding event that does not exist yet (v4 spec section 6 explicitly
# defers "any regional grouping of dynamically-founded communities" to
# that future wave). This is a deliberate, named gameplay concession,
# not a claim that Speyer's Kehillah is historically attested this
# early -- the same honesty standard this mod applies to every
# ESTIMATED-vs-DOCUMENTED distinction elsewhere (see e.g.
# history/characters/worms_1066.txt's header).
#
# THE FIGURE. Not a specific documented individual -- no named person is
# attested this early. "Kalonymus" is used as a GIVEN name (the Mainz
# Kalonymus family used it as both a personal name across generations --
# e.g. Kalonymus ben Moshe, Kalonymus ben Meshullam -- and as the family
# name itself), representing an unnamed member of that same documented
# family, mirroring how this mod already handles Worms's three seeded
# "notable families" (kehillah_seed_community_effect) as representative
# rather than specific attested people. Dynasty: dynn_Kalonymus (ID
# 9000002, already reserved in common/dynasties/ha_levi.txt) -- the
# real, documented family, not invented for this file.
#
# GAMEPLAY CONSEQUENCE OF THE ANACHRONISM: Speyer starts with a
# noticeably smaller communal chest and no Greatness head start (see
# history/titles/kehillah_titles.txt and common/scripted_effects/
# kehillah_scripted_effects.txt's kehillah_setup_speyer_start_effect),
# unlike Worms and Mainz's founding-scholar bonuses -- reflecting that
# in 1066 this is a handful of recent arrivals, not an established
# communal institution.
#
# Faith/culture: rabbinism/ashkenazi, same basis as every other
# character in this scenario. Birth estimated younger than Worms/Mainz's
# leaders (a recent arrival building something new, not an elder
# heading an existing institution) -- ESTIMATED FOR GAMEPLAY PURPOSES,
# not attested.
# =====================================================================
