# dates below.
#
# DATES. Each birth and death says whether it is documented or estimated.

# plausible age on the bookmark day; it is not a claim about the person.

# them forward.
#
# TRAITS. Education and the Rabbi trait follow the role; a lifestyle trait
# is given only where the role is documented (Maimonides the physician,
# Eldad the traveller). No personality traits: none of these is securely
# known.
