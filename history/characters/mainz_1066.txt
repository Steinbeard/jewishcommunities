# =====================================================================
# Isaac ben Judah of Mainz — head of the Mainz rabbinical school.
#
# Source of truth: v4 spec section 5 (docs/spec/v4-regional-communities-
# and-batei-din.md), which flags this as implementation-time research,
# not resolved by the spec itself. Researched 2026-09-08 against the
# Jewish Encyclopedia (this mod's established source for figures of this
# period, per docs/scenarios/worms-1066.md's own sourcing convention).
#
# DOCUMENTED FACT:
#   - Isaac ben Judah of Mainz, an 11th-century Talmudist, headed the
#     rabbinical schools of Mainz and (later) Worms, and was one of
#     Rashi's own teachers -- Jewish Encyclopedia: "ISAAC BEN JUDAH".
#     His commentaries are cited by Rashi directly, and his responsa
#     survive scattered across later rabbinic compilations (Pardes
#     ha-Gadol, Or Zarua, Shibbole ha-Leket).
#   - Native of Lorraine, studied under Eleazar ha-Gadol in Germany
#     before heading the Mainz school himself.
#   - Faith: rabbinism. Culture: ashkenazi. Same basis as every other
#     character in this mod's Rhineland scenario.
#
# NOT DOCUMENTED, AND DELIBERATELY LEFT THAT WAY:
#   - No dynasty/surname is attested for him anywhere -- he is
#     consistently "Isaac ben Judah" (son of Judah), never given a
#     family name the way Isaac ben Eliezer ha-Levi's Levite descent
#     gives Worms's leader "HaLevi" (see history/characters/
#     worms_1066.txt). Rather than invent one, he is left dynasty-less
#     (lowborn) here -- an honest gap, not an oversight.
#   - No birth or death year is documented at all, only "11th century."
#     Per this mod's established convention (see worms_1066.txt's own
#     header) for a figure who needs to plausibly be a senior, already-
#     established authority by the 1066 scenario date (he already
#     headed a rabbinical school and had already taught Rashi, who by
#     1066 had left for Troyes), an estimated birth of c. 995 is used --
#     ESTIMATED FOR GAMEPLAY PURPOSES, matching Worms's Isaac's own
#     c. 1000 estimate for the identical reason. No death date is set
#     at all (unlike Worms's Isaac, whose c. 1070 death IS documented):
#     inventing one here would manufacture a fact with zero source
#     behind it. He lives out a natural lifespan under the game's own
#     mortality systems instead.
#   - Traits are not documented (see worms_1066.txt's header for why
#     this is normal practice for this mod, mirroring vanilla's own
#     treatment of real historical religious figures without a recorded
#     personality). Chosen to fit his documented profile:
#       - education_learning_4: matches a school head and a teacher
#         whose commentaries Rashi himself cited.
#       - theologian: the same lifestyle-scholarship trait Worms's
#         Isaac carries, equally apt for a rabbinical-school head.
#       - compassionate: one of Judaism's own three listed virtues
#         (common/religion/religions/00_judaism.txt), and deliberately
#         the one NOT already used for Worms's Isaac (who has just and
#         patient) -- gives Mainz's leader a distinct profile rather
#         than a reskin.
#   - kehillah_rabbi_trait (common/traits/kehillah_traits.txt): he
#     heads a rabbinical school by documented fact, same basis Worms's
#     Isaac has it on.
# =====================================================================
9000101 = {
	name = "Isaac"
	religion = "rabbinism"
	culture = "ashkenazi"

	trait = education_learning_4
	trait = theologian
	trait = compassionate
	trait = kehillah_rabbi_trait

	995.1.1 = { # ESTIMATED -- see header. Not an attested birth date.
		birth = "995.1.1"
	}
}
