# Shlomo Yitzhaki ("Rashi") — the Kehillah of Troyes.
#
# Source of truth: docs/spec/v6-minhag-regions.md section 3a, which names
# him explicitly and calls Troyes the flagship illustration of the
# Development-versus-Greatness split this pass is built around.
#
# DOCUMENTED FACT, HIGH CONFIDENCE: Rabbi Shlomo ben Yitzhak (the
# acronym "Rashi"), born in Troyes in 1040, is the single most widely
# read commentator on the Tanakh and Talmud in the whole subsequent
# Jewish tradition. He is also already established in this mod's own
# history -- Worms's Isaac ben Eliezer ha-Levi (history/characters/
# worms_1066.txt) and Mainz's Isaac ben Judah (history/characters/
# mainz_1066.txt) are both his own real, documented teachers, so his
# birth and studies under them are already implied by files this mod
# ships. Faith: rabbinism. Culture: ashkenazi, same basis as every other
# figure in this scenario. Dynasty: dynn_Yitzhaki (ID 9000003, common/
# dynasties/ha_levi.txt) -- already reserved in this mod's dynasty file
# for exactly this name, not invented for this task.
#
# THE DEVELOPMENT-VERSUS-GREATNESS POINT, STATED PLAINLY. At this
# scenario's 1066.9.15 start Rashi is 26 -- newly returned (or returning)
# to Troyes from his studies at Mainz and Worms, not yet the author of
# the commentaries that made him who he became; his major written work
# accumulates over the following four decades. So his community's
# starting Development (3, per v6 spec section 3a's own table -- a
# genuinely young, unglamorous material start) is exactly what a plain
# read of 1066 Troyes would suggest. His Greatness bonus is set
# considerably higher anyway (140, common/scripted_effects/kehillah_
# scripted_effects.txt's kehillah_setup_troyes_start_effect) -- not
# because the community had already achieved eminence by 1066, but
# because the player is handed a specific, real, extraordinarily
# consequential person, and this mod's whole "Development ≠ Greatness"
# framing (v6 spec section 3) exists to let a start like this read as
# "everyone will one day have heard of this place" without needing the
# gold in the chest to already justify it. Pitched below Mainz's 180 (an
# elder who, in-fiction, already led a school and taught Rashi himself)
# and Worms's 150 for the same reason -- 26 is genuinely early -- but
# well above what Dev 3 alone would suggest, matching the spec's own
# explicit instruction to get the relative ordering right (out-ranking
# Paris despite Paris's own lower Development) rather than fixate on an
# exact number.
#
# ESTIMATED / HEDGED FOR GAMEPLAY PURPOSES:
#   - Traits: not documented (see worms_1066.txt's header for why this is
#     normal practice here). education_learning_4 matches Mainz/Worms's
#     own scholarly leaders (education_learning_5 considered and
#     rejected for the same reason Worms's file rejected it -- it bundles
#     +3 Intrigue, unrelated schemer flavor). theologian for the
#     lifestyle-scholarship match. just and patient, two of Judaism's own
#     three listed virtue traits (common/religion/religions/
#     00_judaism.txt), matching Worms's own pair -- Rashi's own
#     commentarial method (patient, exhaustive attention to the plain
#     meaning of a text) is a real, if informal, match for "patient"
#     specifically.
#   - kehillah_rabbi_trait (common/traits/kehillah_traits.txt): granted
#     directly, the same basis Worms's and Mainz's leaders have it on --
#     he already holds recognized rabbinic standing at 26, not merely
#     "on his way to" it.
#   - Death, 1105.1.1: the year 1105 is well documented across sources
#     (his traditional yahrzeit is 13 Tammuz, still commemorated), but
#     the exact Gregorian day is a Hebrew-calendar conversion this task
#     does not attempt to verify precisely, so 1.1 stands in as a
#     placeholder for the day/month only -- mirroring this mod's own
#     established practice (see worms_1066.txt's header) for a death
#     whose YEAR is solid but whose exact day is not independently
#     re-derived here.
# =====================================================================
