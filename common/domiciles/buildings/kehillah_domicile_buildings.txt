# =====================================================================
# Kehillah Quarter buildings.
#
# Source of truth: docs/spec/v1-kehillah-community.md section 3c, which
# maps each vanilla estate slot family onto a Kehillah building. This
# file implements that table.
#
# Two rules the spec insists on, both honoured here:
#
#  1. We reuse the SLOT STRUCTURE, not vanilla's modifiers. Several
#     vanilla estate buildings grant Intrigue and scheme bonuses; the
#     Kehillah design explicitly rejects scheming as a pillar (spec
#     section 2). Every modifier below is written fresh.
#
#  2. Officers gate on BUILDINGS, not just currency. The Beit Midrash,
#     Countinghouse and Shtadlan's Chambers each set a domicile
#     parameter, and the matching court position checks for it in its
#     valid_position block. See
#     common/court_positions/types/kehillah_officers.txt.
#
# NOTE ON PARAMETERS: per common/domiciles/buildings/_domicile_buildings.info,
# "Parameters are not inherited from previous_building and has to be
# repeated to not get lost on upgrading." Every tier therefore repeats
# its parameters. Do not tidy these away.
#
# Art is vanilla base-game estate art referenced by path -- see the
# header of common/domiciles/types/kehillah_domicile_types.txt for why.
# The generic (non-Christian, non-Islamic) temple texture is used for
# the Synagogue.
# =====================================================================


# =====================================================================
# MAIN SLOT -- THE SYNAGOGUE
#
# The community's visible growth arc. Each tier unlocks internal slots,
# so the Synagogue is what literally makes room for everything else.
#
# Slot budget: tiers 1-5 give 2/3/4/5/6 internal slots. Six is exactly
# the number of v1 internal buildings, which means a fully grown
# Synagogue can host all of them and no more. The seventh conceptual
# slot -- the Genizah, spec section 3c's reserved Phase 5 hidden chamber
# -- is deliberately NOT reachable in v1. Raise the tier-5 number to 7
# when Phase 5 adds it.
# =====================================================================
