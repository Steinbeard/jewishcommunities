# =====================================================================
# Kehillah pillar breakdown LINES.
#
# ADDED 2026-09-15 (v12 section 8). One customizable-loc function per
# line of the per-score tooltips. Each returns either its line -- with
# the line's own newline INSIDE it -- or an empty string, so the tooltip
# text (localization/english/kehillah_breakdown_l_english.yml) is just
# the lines concatenated and absent contributors leave no gap. This is
# the only way to get "show this line only if" out of the loc system,
# which has no conditionals of its own; a custom-loc function picks the
# FIRST matching text, so one function = one line.
#
# type = character: the community's leader, the scope every baseline
# term is defined on. Callers reach it from a title as
# [Title.GetHolder.Custom('KehillahBd...')] (the map view) or from a
# decision as [ROOT.Char.Custom('KehillahBd...')] (ROADMAP item 4, a
# decision-based Take Stock breakdown, was CLOSED 2026-09-23 as no
# longer needed -- the map view already covers this. If a future
# session still wants a decision-based version instead, every line
# here can still be reused unchanged; nothing below needs to change
# for that to work).
#
# kehillah_bd_none is the empty string; see its note in the loc file.
# =====================================================================
