# Charter Revised" names what changed: one function per charter term,
# each a line like "Building: Charter Permission Required (was Free to
# Build)" when that term moved this quarter, or nothing. Reads the cache
# (kehillah_charter_cache_*) against last quarter's values
# (kehillah_charter_prev_*), both set by kehillah_refresh_charter_state_
# cache_effect. Scope: the community title. The term names are the
# charters' own obligation names.
# =====================================================================
