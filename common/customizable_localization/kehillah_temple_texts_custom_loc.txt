# been built). Each text about the Bavli's Kodashim has two versions: the
# Temple's service absent (the default, as in history), and the service
# restored in Jerusalem (kehillah_restore_temple_service_decision,
# title:c_jerusalem's kehillah_temple_service_restored). Used through
# GetPlayer.Custom, so it reads the same wherever it is shown.
