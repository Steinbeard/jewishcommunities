# =====================================================================
# HaLevi dynasty — for Isaac ben Eliezer ha-Levi, chief rabbi of Worms.
#
# Source of truth: docs/scenarios/worms-1066.md (this mod), §3 and §5.
# Scope note: this file defines ONLY the dynasty. Isaac's character
# entry lives in history/characters/worms_1066.txt. No title, government,
# or bookmark content is defined here — that is out of scope for this
# task and is being designed separately.
#
# Dynasty name: "HaLevi" is taken directly from Isaac's own documented
# epithet/lineage marker (Levite descent) — NOT an invented surname. See
# the scenario doc §3 sourcing (Jewish Encyclopedia, Encyclopedia.com;
# some sources transliterate the patronymic as "Eleazar" vs "Eliezer" —
# same person, unrelated to this dynasty-name point).
#
# ID choice: 9000001.
#   This mod reserves the 9,000,000-9,999,999 ID block for its own
#   custom dynasties, to avoid colliding with vanilla or other mods'
#   IDs, which was verified as follows against the installed 1.19
#   vanilla game files (checked directly, not assumed):
#     - Every vanilla common/dynasties/*.txt file was grepped for IDs
#       matching 9000000-9999999 -> zero hits.
#     - Vanilla dynasty IDs otherwise run from small numbers up to
#       ~10,290,903 (still outside our reserved block) before jumping to
#       a separate ~1,000,000,000+ block clearly reserved for later
#       Paradox DLC content.
#   9000001 is therefore comfortably clear of vanilla's ID space. It
#   cannot be verified against every other third-party mod that might
#   ever be loaded alongside this one, but a distinctive high value far
#   from vanilla's normal ranges is the standard mitigation for that.
# =====================================================================

	name = "dynn_HaLevi"
