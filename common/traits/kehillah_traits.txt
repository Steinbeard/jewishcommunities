# =====================================================================
# The Rabbi trait.
#
# Considered and rejected: reskinning an existing lifestyle trait
# (scholar was the specific suggestion) to display as "Rabbi" for
# Jewish characters. Rejected because scholar is earned through the
# Learning lifestyle tree by ANY character, religious or not -- a
# brilliant but entirely secular Jewish physician or mathematician can
# and does earn it. Reskinning its display name by faith would put
# "Rabbi" on that character too, which is simply wrong, not just
# imprecise. A trait needs its own identity to mean "this specific
# person holds religious authority", not "this person is smart and
# happens to be Jewish".
#
# ACQUISITION -- REVISED 2026-09-09, at user request, from the original
# two-source design to three:
#   1. Holding the Chief Rabbi court position (see
#      common/court_positions/types/kehillah_officers.txt's
#      on_court_position_received/revoked/invalidated/vacated hooks).
#   2. Isaac ben Eliezer's own history entry
#      (history/characters/worms_1066.txt) -- he is already documented
#      as chief rabbi and yeshiva head, so he starts with it rather
#      than waiting to be inferred from other traits.
#   3. NEW: sitting on a Bet Din Conference panel at all, as host or
#      co-judge -- kehillah_bet_din_grant_rabbi_trait_effect (common/
#      scripted_effects/kehillah_bet_din_scripted_effects.txt), called
#      from kehillah_bet_din_open_docket_effect on all three judges once
#      the panel is set. "You become a rabbi when you go to a bet din as
#      a judge" was the literal request -- judging is now, on its own,
#      sufficient, not just office-holding or starting history. NOT
#      silent, per a same-day follow-up request: this is an offer, not
#      a grant -- kehillah_bet_din_semicha.0001 (events/kehillah_bet_
#      din_semicha_events.txt) lets the judge accept semicha or decline
#      it (offered again next time they judge, not permanently refused).
# This also makes it the clean, direct signal for
# kehillah_leader_is_rabbinic_trigger (common/scripted_triggers/
# kehillah_scripted_triggers.txt), which previously had to infer
# "reads as a rabbi" from theologian/education traits and a raw
# Learning threshold because no dedicated trait existed yet. Those
# stay in the trigger as a fallback -- a leader can plausibly read as
# rabbinic on scholarly reputation alone without ever having held the
# Chief Rabbi office specifically (the ruler cannot hold their own
# community's court positions; only a courtier can).
#
# category = lifestyle, CHANGED 2026-09-09 at user request (was fame).
# The original reasoning for fame -- staying outside the lifestyle-trait
# slot limit, since this was granted by script rather than earned --
# assumed that slot limit is enforced BY the category field itself.
# Checked against vanilla before making this change: theologian and
# scholar (common/traits/00_traits.txt) are BOTH category = lifestyle
# and routinely coexist on the same character (an education trait plus
# an adult lifestyle-commitment trait) -- so category alone does not
# force single-slot exclusivity; whatever DOES enforce "only one adult
# lifestyle commitment" lives in the commitment interactions themselves,
# which this trait was never part of anyway. So there was no real
# tradeoff being protected, and category = lifestyle now correctly
# reads this trait as what it has become: a path with real track
# progression, not a static badge.
#
# icon reuses theologian.dds rather than new art, per this mod's
# established art policy (see common/domiciles/types/
# kehillah_domicile_types.txt's header) -- same reasoning: it is the
# closest existing semantic match, and Isaac himself already carries
# the theologian trait, so the visual continuity is a feature, not a
# shortcut.
#
# TRACKS: three real, XP-driven tracks -- parshanut (biblical exegesis),
# talmudics (Talmudic/halakhic argumentation and legal ruling), hashkafa
# (worldview -- philosophy, mysticism, engaging Greek/Arabic learning).
# BASE bonus (learning/piety, present regardless of any track progress)
# sits on the trait directly, below; each track then layers THREE reward
# thresholds on top (30/65/100, engine-capped at 100), the third added
# specifically to give "each tier a different quality of book" (below)
# three real quality levels to land on, not two.
#
# UPDATED 2026-09-15 at user request: the original three tracks (added
# 2026-09-09) were parshanut/talmudics/halakha. halakha is RETIRED as a
# separate track and folded into talmudics -- "Talmudic argumentation"
# and "legal ruling" were never actually distinct activities in how this
# mod granted XP for them (every Bet Din case resolution granted BOTH,
# at the same amount, on every tier -- see the note below), so treating
# them as one track reads truer than the original split did, not just
# simpler. Merged talmudics' own threshold bonuses below are the union
# of both tracks' old bonuses (diplomacy from the old talmudics,
# stewardship from the old halakha), not a fresh invention.
#
# REMOVED 2026-09-19 at user request: Bet Din case resolutions no longer
# grant trait_xp on any track at all (kehillah_rabbi_grant_case_xp_effect
# and kehillah_bet_din_grant_parshanut_xp_effect, both formerly in
# common/scripted_effects/kehillah_bet_din_scripted_effects.txt, are
# gone). The Bet Din's own reward for judging is now the session-closing
# event's tiered Stability/Piety/Prestige payout (kehillah_bet_din.0099,
# events/kehillah_bet_din_events.txt) -- earned by the WHOLE docket
# having gone well, not paid out per case regardless of outcome.
# kehillah_learn_torah_decision (below) is therefore now the ONLY route
# that trains any of these three tracks.
#
# hashkafa is NEW, replacing halakha's vacated third slot: the rabbi's
# own engagement with the wider intellectual world -- Geonic and
# Andalusi Jewish philosophy, early mysticism, and (per explicit user
# framing) the same Greek-via-Arabic and Arabic-poetic material the
# Translation Contract already deals in. Its own threshold bonus,
# opinion_of_different_faith (a real, already-used vanilla character-
# modifier field -- zealous's own opposite_opinion/opinion_of_different_
# faith block, common/traits/00_traits.txt, is the confirmed precedent),
# is deliberately distinct from parshanut's piety-lean and talmudics'
# diplomacy/stewardship-lean: broadened worldview reading as broadened
# tolerance, not more of either existing track's own flavor.
#
# WHO GAINS XP AND WHEN: kehillah_learn_torah_decision (common/decisions/
# kehillah_learn_torah_decisions.txt) -- a real study session at the Beit
# Midrash, gated on the community's own library actually holding a
# relevant work (common/scripted_effects/kehillah_library_effects.txt) --
# is the ONLY route, genre-neutral across all three tracks. Bet Din
# judging no longer grants any trait_xp at all (REMOVED 2026-09-19, see
# above); it rewards the community instead, via the docket's own
# session-closing Stability/Piety/Prestige payout.
# =====================================================================

# Reader variables for `compatibility` blocks below. CK3's `@variable`
# reader directives are file-scoped -- vanilla defines these same names
# and values at the top of common/traits/00_traits.txt, but that
# definition isn't visible here, in a separate mod file (caught by
# ck3-tiger, 2026-09-07: "reader variable ... not defined"). Values
# copied verbatim from vanilla's "Standard Values" block so compatibility
# here means the same thing it would in a vanilla trait.
@pos_compat_medium = 15
@pos_compat_low = 5
@neg_compat_low = -5

kehillah_rabbi_trait = {
	category = lifestyle
	icon = theologian.dds

	# BASE bonus -- present from the moment this trait is held, before
	# any track XP at all. "A little extra piety and learning," per user
	# request: learning was already +2 from the original design; added a
	# small flat monthly_piety alongside the existing gain-MULTIPLIER so
	# there is a real, literal "gains a little extra piety" line too, not
	# only "gains piety faster."
	learning = 2
	monthly_piety = 0.1
	monthly_piety_gain_mult = 0.15
	same_faith_opinion = 5

	shown_in_ruler_designer = no

	compatibility = {
		theologian = @pos_compat_medium
		scholar = @pos_compat_medium
		just = @pos_compat_low
		compassionate = @pos_compat_low
		arbitrary = @neg_compat_low
		cynical = @neg_compat_low
	}

	# Three thresholds per track (30/65/100 -- see the UPDATED note just below) -- vanilla's own lifestyle_
	# hunter tracks (common/traits/00_traits.txt) only use two, but this
	# needed a third specifically so the book-writing decisions below
	# (common/decisions/kehillah_rabbi_book_decisions.txt) have three
	# real quality tiers to land on, the top one reading as "legendary"
	# and not just "the better of two options." See this file's header
	# for who actually grants this XP and when.
	# UPDATED 2026-09-09: thresholds are 30/65/100, not 50/100/150 --
	# ck3-tiger caught this immediately ("trait xp only goes up to 100")
	# before it ever reached a live game: trait XP is hard-capped at 100
	# by the engine, so 150 was never reachable. This turns out to read
	# BETTER than the original plan, not worse -- 100 = fully maxing the
	# track is a more literal match for "COMPLETING one of the tracks"
	# ungating the legendary book than an arbitrary 150 ever was.
	tracks = {
		parshanut = {
			30 = {
				learning = 1
				monthly_piety = 0.2
			}
			65 = {
				learning = 1
				monthly_piety = 0.3
				same_faith_opinion = 5
			}
			100 = {
				learning = 1
				monthly_piety = 0.4
				same_faith_opinion = 5
				monthly_prestige = 0.3
			}
		}
		# MERGED 2026-09-15 -- the union of the old talmudics (diplomacy)
		# and old halakha (stewardship) threshold bonuses; see this file's
		# own header above for why the two tracks were folded into one.
		talmudics = {
			30 = {
				learning = 1
				diplomacy = 1
				stewardship = 1
			}
			65 = {
				learning = 1
				diplomacy = 1
				stewardship = 1
				same_faith_opinion = 5
			}
			100 = {
				learning = 1
				diplomacy = 1
				stewardship = 1
				same_faith_opinion = 5
				monthly_prestige = 0.5
			}
		}
		# NEW 2026-09-15, replacing halakha's vacated third slot -- see
		# this file's own header above for the full account of what
		# hashkafa covers and why opinion_of_different_faith specifically.
		hashkafa = {
			30 = {
				learning = 1
				opinion_of_different_faith = 5
			}
			65 = {
				learning = 1
				opinion_of_different_faith = 10
				same_faith_opinion = 5
			}
			100 = {
				learning = 1
				opinion_of_different_faith = 15
				same_faith_opinion = 5
				monthly_prestige = 0.3
			}
		}
	}
}
