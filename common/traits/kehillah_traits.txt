# =====================================================================
# The Rabbi trait.
#
# Considered and rejected: reskinning an existing lifestyle trait
# (scholar was the specific suggestion) to display as "Rabbi" for
# Jewish characters. Rejected because scholar is earned through the
# Learning lifestyle tree by ANY character, religious or not -- a
# brilliant but entirely secular Jewish physician or mathematician can
# and does earn it. Reskinning its display name by faith would put
# "Rabbi" on that character too, which is simply wrong, not just
# imprecise. A trait needs its own identity to mean "this specific
# person holds religious authority", not "this person is smart and
# happens to be Jewish".
#
# ACQUISITION: not a lifestyle-tree trait, so no perk track. Granted
# directly by two things instead --
#   1. Holding the Chief Rabbi court position (see
#      common/court_positions/types/kehillah_officers.txt's
#      on_court_position_received/revoked/invalidated/vacated hooks).
#   2. Isaac ben Eliezer's own history entry
#      (history/characters/worms_1066.txt) -- he is already documented
#      as chief rabbi and yeshiva head, so he starts with it rather
#      than waiting to be inferred from other traits.
# This also makes it the clean, direct signal for
# kehillah_leader_is_rabbinic_trigger (common/scripted_triggers/
# kehillah_scripted_triggers.txt), which previously had to infer
# "reads as a rabbi" from theologian/education traits and a raw
# Learning threshold because no dedicated trait existed yet. Those
# stay in the trigger as a fallback -- a leader can plausibly read as
# rabbinic on scholarly reputation alone without ever having held the
# Chief Rabbi office specifically (the ruler cannot hold their own
# community's court positions; only a courtier can).
#
# category = fame, not lifestyle: this is a recognized status the
# community accords someone, not a personally chosen life path, and
# fame-category traits (see vanilla's excommunicated for the same
# category choice) sit outside the lifestyle-trait slot limit, which
# matters because this trait is granted by script rather than earned
# through the normal lifestyle-progression UI that limit is meant to
# ration.
#
# icon reuses theologian.dds rather than new art, per this mod's
# established art policy (see common/domiciles/types/
# kehillah_domicile_types.txt's header) -- same reasoning: it is the
# closest existing semantic match, and Isaac himself already carries
# the theologian trait, so the visual continuity is a feature, not a
# shortcut.
# =====================================================================

# Reader variables for `compatibility` blocks below. CK3's `@variable`
# reader directives are file-scoped -- vanilla defines these same names
# and values at the top of common/traits/00_traits.txt, but that
# definition isn't visible here, in a separate mod file (caught by
# ck3-tiger, 2026-09-07: "reader variable ... not defined"). Values
# copied verbatim from vanilla's "Standard Values" block so compatibility
# here means the same thing it would in a vanilla trait.
@pos_compat_medium = 15
@pos_compat_low = 5
@neg_compat_low = -5

kehillah_rabbi_trait = {
	category = fame
	icon = theologian.dds

	learning = 2
	monthly_piety_gain_mult = 0.15
	same_faith_opinion = 5

	shown_in_ruler_designer = no

	compatibility = {
		theologian = @pos_compat_medium
		scholar = @pos_compat_medium
		just = @pos_compat_low
		compassionate = @pos_compat_low
		arbitrary = @neg_compat_low
		cynical = @neg_compat_low
	}
}
