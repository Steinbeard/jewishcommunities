# =====================================================================
# Map-colour titles for the Jewish Communities map mode.
#
# These are not titles anyone can hold. They exist only to carry a
# colour that set_color_from_title can copy onto a barony, which is the
# one script-drivable input to CK3's map colouring: the "baronies"
# color_mode paints each barony in its own title's colour, and
# set_color_from_title (vanilla effect, e.g. common/casus_belli_types/
# 07_ep3_wars.txt:6188, common/scripted_effects/00_administrative_
# effects.txt:545) rewrites that colour at runtime. Technique per the
# CK3 wiki's "Creating Custom Map Modes"; see docs/spec/v12-community-
# map-view.md section 2.5 for how this mod uses it and what it costs.
#
# Titular (no de jure counties), can never be created, never granted.
# can_create = { always = no } is the wiki's own guard and is what
# keeps them out of every "create title" decision.
#
# One colour per Standing band (kehillah_band_*_threshold, common/
# script_values/kehillah_script_values.txt) plus the neutral base every
# other barony is painted. RGB 0-255. The band ramp reads cold-to-warm
# from crisis to legendary so it is legible without a legend; the base
# is a muted parchment grey close to vanilla's own data-map neutral.
# =====================================================================
