# =====================================================================
# Jewish holiday scripted triggers.
#
# Unlike the Kehillah triggers, these are answered by FAITH, not by
# government type -- they have to fire for any Jewish character on the
# map (courtiers, other rulers, the Kehillah leader, everyone), not only
# the one non-landed government seat.
#
# Vanilla's judaism_religion contains seven faiths (see
# common/religion/religion_types/00_judaism.txt): rabbinism, karaism,
# haymanot, malabarism, samaritan, kabarism, merkabah. They do not all
# observe the same calendar of holidays, and pretending otherwise would
# be worse than picking nothing:
#
#   - The five Torah-mandated festivals of Leviticus 23 -- Rosh
#     Hashanah, Yom Kippur, Sukkot, Passover, Shavuot -- are kept in some
#     form across all seven. is_jewish_character_trigger below is the
#     gate for these.
#   - Hanukkah commemorates the Maccabean rededication of the Second
#     Temple. It is not in the Tanakh at all -- its story is Talmudic
#     (tractate Shabbat) and apocryphal (1-2 Maccabees), transmitted
#     through rabbinic authority. Faiths built on a different halakhic
#     authority never received it. is_rabbinic_authority_jewish_trigger
#     is the gate.
#   - Purim depends on the Book of Esther, which is canonical to the
#     faiths that share the wider Hebrew Bible (Tanakh) but not to
#     Samaritanism, whose canon is the Samaritan Torah alone, nor
#     historically to Haymanot, isolated from Ketuvim transmission
#     before modern contact. is_hebrew_canon_jewish_trigger is the gate.
#
# Scope: a character, for all three.
# =====================================================================


# ---------------------------------------------------------------------
# is_jewish_character_trigger
#
# Any practitioner of Judaism, of any faith in the religion group. Use
# this alone for the Torah-mandated festivals every Jewish faith shares.
# ---------------------------------------------------------------------

is_jewish_character_trigger = {
	faith.religion = religion:judaism_religion
}


# ---------------------------------------------------------------------
# is_rabbinic_authority_jewish_trigger
#
# The three faiths that recognise rabbinic/Talmudic legal authority
# (doctrine = temple_authority_rabbinic_doctrine in the faith files):
# rabbinism itself, kabarism (the Khazar-descended rabbinic variant),
# and merkabah (mystical, but still rabbinic in its halakha). Gate for
# post-Torah, Talmudic-origin observances -- Hanukkah today.
#
# Combine with is_jewish_character_trigger where it isn't already
# implied by context; it is not repeated here to keep this trigger
# reusable on its own.
# ---------------------------------------------------------------------

is_rabbinic_authority_jewish_trigger = {
	OR = {
		faith = faith:rabbinism
		faith = faith:kabarism
		faith = faith:merkabah
	}
}


# ---------------------------------------------------------------------
# is_hebrew_canon_jewish_trigger
#
# is_rabbinic_authority_jewish_trigger's three faiths, plus karaism
# (literalist about the wider Tanakh, including Esther, even while
# rejecting rabbinic authority over it) and malabarism (the Cochin
# community, isolated from mainstream rabbinic institutions but not
# from the Hebrew Bible itself). Excludes samaritan (a narrower canon
# by doctrine) and haymanot (isolated from Ketuvim transmission).
# Gate for Purim.
# ---------------------------------------------------------------------

is_hebrew_canon_jewish_trigger = {
	OR = {
		is_rabbinic_authority_jewish_trigger = yes
		faith = faith:karaism
		faith = faith:malabarism
	}
}
