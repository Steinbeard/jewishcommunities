# Write a Book.

# ADDED 2026-09-09; FLESHED OUT the same day at user request. Originally
# three separate decisions (one per kehillah_rabbi_trait track), each
# resolving in one instant effect. Replaced with ONE decision that opens
# a real event chain (events/kehillah_book_events.txt) -- genre choice,
# inspiration, a courtier discussion, a revision choice, then the book
# is finished and copies go out to nearby communities. See kehillah_
# has_eligible_book_genre_trigger's own header (common/scripted_

# Was distinct from kehillah_compose_commentary_decision (kehillah_
# decisions.txt) on purpose: that one was gated on the COMMUNITY's
# Greatness pillar and produced one generic commentary in one step; this
# is gated on ONE PERSON's own accumulated expertise (or, for poetry,
# their own lifestyle_poet trait) and is a real multi-step chain about
# writing a specific book on a specific subject.
#
# UPDATE, 2026-09-15: kehillah_compose_commentary_decision is RETIRED --
# see its own retirement note in kehillah_decisions.txt. This is now the
# ONLY "compose a scholarly work" decision this mod offers. The same
# pass added a Talmudics/Halakha-specific inspiration option to kehillah_
# book.0002 (events/kehillah_book_events.txt) that draws on a character's
# own memory of a good Bet Din ruling, if they have one -- see that
# event's own header and kehillah_has_good_bet_din_memory_trigger
# (common/scripted_triggers/kehillah_scripted_triggers.txt).
# =====================================================================
