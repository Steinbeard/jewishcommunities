# ============================================================================
# Overrides vanilla's Israelite-heritage culture name lists
# (common/culture/name_lists/00_israelite.txt), which as shipped has
# ashkenazi and sephardi sharing one identical Gaonic/Talmudic-Babylonian
# name pool (Baboi, Paltoi, Yehudai, Natronai...) verbatim, and both
# bavlim and kochinim (common/culture/cultures/00_israelite.txt) pointing
# at name_list_radhanite instead of having their own.
#
# Structure:
#  - Every list below shares one cross-cultural "core": Biblical and
#    Second Temple names attested across all Jewish communities, PLUS
#    names tied to specific faiths (Tannaitic/Amoraic sages for
#    Rabbinism, early Karaite scholars for Karaism, the Aaronide
#    priestly line for Samaritanism, Hekhalot mystics for Merkabah).
#    Those faith-tied names are made exclusive to their faith via
#    reserved_male_names/reserved_female_names in
#    kehillah_judaism_reserved_names.txt - putting them in every list
#    here just makes them available to draw from; the faith reservation
#    is what actually restricts who receives them.
#  - Ashkenazi, Sephardi, Radhanite and Bavlim then each layer their own
#    distinctive flavor on top (Yiddish/Germanic, Judeo-Iberian/Arabic,
#    Judeo-Persian trade-route, Gaonic/Judeo-Aramaic).
#  - Kochinim (Cochin Jews, historically very conservative in naming)
#    intentionally keeps to the shared core without an invented layer.
#  - Kabarism (Khazar Judaism) names live in a separate override of
#    name_list_khazar (see kehillah_khazar_kabarism_patch.txt), since its
#    adherents are of Khazar (Turkic) culture, not one of these.
# ============================================================================
