# ============================================================================
# Overrides vanilla's bavlim and kochinim culture objects (defined in
# common/culture/cultures/00_israelite.txt) solely to point them at their
# own dedicated name lists (name_list_bavlim, name_list_kochinim, added in
# kehillah_israelite_names.txt) instead of both sharing name_list_radhanite
# as vanilla ships them. CK3 overrides database objects by key, so every
# other field must be copied unchanged from vanilla to avoid losing it.
#
# Also ADDS two cultures vanilla has none of, under the same heritage_
# israelite group: romaniote (the historic Jewish community of the
# Byzantine world - Constantinople, Thessaloniki, the Balkans, western
# Anatolia, since antiquity) and italki (Italy's own continuous Jewish
# community since Roman times). Both are wired into
# kehillah_pool_repopulation_patch.txt's random_culture logic so newly
# generated Jewish characters actually spawn as these cultures in their
# native regions instead of defaulting to ashkenazi.
# ============================================================================
