# ============================================================================
# Overrides vanilla's bavlim and kochinim culture objects (defined in
# common/culture/cultures/00_israelite.txt) solely to point them at their
# own dedicated name lists (name_list_bavlim, name_list_kochinim, added in
# kehillah_israelite_names.txt) instead of both sharing name_list_radhanite
# as vanilla ships them. CK3 overrides database objects by key, so every
# other field must be copied unchanged from vanilla to avoid losing it.
#
# Also ADDS two cultures vanilla has none of, under the same heritage_
# israelite group: romaniote (the historic Jewish community of the
# Byzantine world - Constantinople, Thessaloniki, the Balkans, western
# Anatolia, since antiquity) and italki (Italy's own continuous Jewish
# community since Roman times). Both are wired into
# kehillah_pool_repopulation_patch.txt's random_culture logic so newly
# generated Jewish characters actually spawn as these cultures in their
# native regions instead of defaulting to ashkenazi.
#
# Also overrides vanilla's ashkenazi and sephardi (fields copied unchanged)
# solely to replace their 100 = arab ethnicity with a mixed one. Each newly
# generated character draws ONE ethnicity by weight; children then blend
# their parents' genes, so a community converges on an in-between look over
# a few generations. Reference points from vanilla: Italian and Iberian
# cultures are 100 = mediterranean, Greek is 100 = mediterranean_byzantine
# (a plain alias of mediterranean today), North African (maghrebi) is
# 91 = arab / 9 = african.
#   ashkenazi         - between Italian and Arab, plus a small share of the
#                       vanilla German looks (no blond): 42 arab / 43
#                       mediterranean / 8 caucasian_brown_hair / 4
#                       caucasian_dark_hair / 3 caucasian_ginger
#   italki            - between Italian and Arab: 50 arab / 50 mediterranean
#   romaniote         - between Greek and Arab: 50 arab / 50 mediterranean_byzantine
#   sephardi          - two-thirds Arab, one-third Iberian: 67 arab /
#                       33 mediterranean (no african weight - judged
#                       unimmersive for Sephardim)
# ============================================================================
